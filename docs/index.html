01 The panel

One small remote

Click B-Side in the Dock on a Mac, or its tray icon on Windows, or open it again, and the panel comes up. Everything it does is in here. Nothing hides in a preferences window.

Jump to MacWindows

Mac

  1. Now playingThumbnail, title, channel and whether it's a playlist. Seek by clicking the bar.
  2. Transport and volumePrevious, play and next. Space, ← → and M work while the panel is open.
  3. Wallpaper or screensaverSwitch at any time. Screensaver ignores a nudge of the trackpad and ends on a click, a key or a proper mouse move.
  4. Paste a link to switchAny video or playlist, even while something plays. ⌘V anywhere in the panel does the same.
  5. LookDim the video so desktop icons stay readable, fill the screen or keep black bars, all screens or the main one only.
  6. RecentThe last eight things you played. A whole mix counts as one.
  7. SettingsSkip still-picture tracks, pause on lock or battery, screensaver after idle, open at login.

Windows

  1. Now playingThumbnail, title, channel and whether it's a playlist. Seek by clicking the bar.
  2. Transport and volumePrevious, play and next, and the volume.
  3. Wallpaper or screensaverSwitch at any time. Screensaver covers the taskbar and ends on a click, a key or a proper mouse move.
  4. Paste a link to switchAny video or playlist, even while something plays.
  5. LookDim the video so desktop icons stay readable, fill the screen or keep black bars, all screens or the main one only.
  6. RecentThe last eight things you played. A whole mix counts as one.
  7. SettingsSkip still-picture tracks, pause on lock or battery, screensaver after idle, open at login.
02 Every screen

Same video, one sound

Plug in a second screen and it plays there too, on the same track at the same second. Sound comes from the main screen, so you hear it once.

03 Keys

Keyboard shortcuts

They work whichever app you're in.

Jump to MacWindows

Mac

Watching something in Chrome? Press ⌃⌥B and it moves behind your windows. Press it again somewhere else and it goes back to Chrome at the same second.

⌃⌥BTake the YouTube video you're watching in Chrome, or send it back
⌃⌥PPlay or pause
⌃⌥← ⌃⌥→Previous or next track
⌃⌥SSwitch between wallpaper and screensaver
⌃⌥MMute

macOS asks once for Accessibility access so the keys work in other apps. Turn them off in Settings if you don't want them.

Windows

Copy a YouTube link, press Ctrl+Alt+B and it plays behind your windows.

Ctrl+Alt+BPlay the link on the clipboard
Ctrl+Alt+PPlay or pause
Ctrl+Alt+Left Ctrl+Alt+RightPrevious or next track
Ctrl+Alt+SSwitch between wallpaper and screensaver
Ctrl+Alt+MMute

If another app already uses one of these keys, B-Side says so in the panel.

What it does and needs

05 Terminal

Or drive it from the shell

Everything the panel does, bside does too.

Mac

It ships in the repo as bin/bside. Link it into your path once.

ln -s "$PWD/bin/bside" ~/.local/bin/bside

Windows

It's bside on Windows too. The app puts the command on your PATH for you, so there is nothing to link.

$ bside                    # open the panel
$ bside on                 # take the video open in Chrome (Mac)
$ bside on screensaver     # same, straight to screensaver (Mac)
$ bside <youtube link>     # play that link
$ bside off                # back to Chrome at the same second (Mac)
$ bside pause | next | prev | mute
$ bside vol 50 | dim 30 | screens main
$ bside status             # what's playing, as JSON
06 Install

Four steps, one honest one

B-Side isn't notarised by Apple yet, so macOS stops it the first time. Step three is how you let it through. You only do it once.

B-Side isn't code-signed yet, so Windows SmartScreen stops it the first time. Step two is how you get past it.

Jump to MacWindows

Mac

  1. 01Download

    B-Side.zip from the latest release, then unzip it.

  2. 02Move it

    Drag B-Side into Applications and open it.

  3. 03Open Anyway

    macOS says it can't check the app. Go to System Settings, then Privacy & Security, scroll down and click Open Anyway.

    System Settings › Privacy & Security › Open Anyway
  4. 04Allow Chrome

    The first time B-Side takes a video from Chrome, macOS asks if it may control Google Chrome. Click Allow.

Optional: in Chrome, turn on View › Developer › Allow JavaScript from Apple Events. B-Side can then pause YouTube in Chrome when it starts playing, and pick up a video at the exact second you were watching.

Windows

  1. 01Download

    B-Side-Setup.exe from the Windows release. It's about 115 MB.

  2. 02Run anyway

    Windows says "Windows protected your PC" because the app isn't code-signed yet. Click More info, then Run anyway.

    Windows protected your PC › More info › Run anyway
  3. 03Install

    It installs for your user only, so it doesn't ask for an administrator password.

  4. 04Paste a link

    B-Side opens its panel. Paste a YouTube link and it plays behind your windows.

Using the portable B-Side-Windows.zip instead? Right-click the .zip, choose Properties and tick Unblock before you unzip it. Otherwise Windows may block the files inside.
